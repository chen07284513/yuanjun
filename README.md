# 援军观察 · 模拟盘

把抖音“狙盘手”的**援军战法**写成固定规则：每个交易日收盘后自动选股，并按规则模拟买卖、记录之后的真实涨跌。
用来观察这个战法灵不灵，**不是投资建议**。

## 怎么用

- 手机打开 GitHub Pages 网址（仓库 Settings → Pages 里能看到），添加到主屏幕后就像 app 一样用。
  - iPhone：Safari → 分享 → 添加到主屏幕
  - 安卓：Chrome → 菜单 → 添加到主屏幕
- 每个交易日北京时间约 14:40–14:50 用盘中价格选股（方便尾盘操作），16:40 收盘后再更新一次模拟盘。GitHub 的定时任务有时会晚几分钟。
- 想马上运行一次：仓库的 **Actions → daily-pick → Run workflow**。

## 规则

**原版**（买点在信号日尾盘，app 按选股时的盘中价格模拟买入）
1. 最近 20 个交易日内出现过 2 连板以上
2. 从最高点回调 15%–40%
3. 回调中最后一个新低当天的最低价 = 撤军线
4. 之后两天都没再跌破撤军线，第二天收阳线
5. 收盘价离撤军线不超过 10%，成交额 ≥ 1 亿，当天没涨停

**严格版**另外要求：回调 20%–50%；中证全指在 20 日线上且当天涨停 ≥ 60 家；撤军线不低于首个涨停板的开盘价；回调期间均量 ≤ 连板期间均量的 60%。

**卖出**（两版相同）：跌破撤军线止损；+8% 止盈；否则第 5 个交易日收盘卖出。模拟收益已扣佣金、印花税和滑点。

## 股票池

沪深主板 + 创业板。不含科创板、北交所和 ST 股。

## 回测（2016-01 至 2026-11，同一股票池，含退市股）

| | 信号数 | 胜率 | 每笔平均（扣费后） | 5 只轮动账户 |
|---|---|---|---|---|
| 原版 | 6,797 | 38% | −0.81% | 约 −100% |
| 严格版 | 386 | 45% | +0.20% | −17%，最大回撤 −23% |

同期沪深 300 约 +10%。另测了 536 组参数，前后两段都赚钱的只有 7 组，每笔最多约 +0.1%。
详见 app 的“回测”页。

## 文件

- `picker/daily.py` 每日任务：拉数据 → 选股 → 更新模拟盘 → 写 `docs/data/*.json`
- `picker/strategy.py` 规则本体（和回测用的是同一份代码）
- `picker/fetch.py` 数据源：东方财富为主，腾讯行情备用
- `docs/` 手机网页 app
